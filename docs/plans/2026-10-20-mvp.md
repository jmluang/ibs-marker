# 肠记 Mobile Web 首版 Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 还原已查看的 Figma 原型，交付可实际记录、刷新恢复、检索统计和导出的单用户移动端应用，并提供可配置的 Supabase 登录/同步与数据库权限脚本。

**Architecture:** React SPA/PWA，领域模型与持久化独立于 UI；IndexedDB 保存记录、草稿和计时状态。未配置云项目时明确为“仅本机保存”；配置 Supabase 后采用独立账号分区、Auth、Postgres RLS 与可重试同步，绝不把本地保存冒充云同步。

**Tech Stack:** React、TypeScript、Vite、Tailwind CSS、IndexedDB、Supabase JS、Vitest、Playwright。

## Task 1：工程与领域基础
**Files:** 根目录构建/测试配置；`src/domain/`、`src/state/`、`src/storage/`、`src/test/`。
- 创建可运行 React+Tailwind 工程和精确锁文件、环境示例及忽略规则；不依赖外部字体/CDN才能使用。
- 定义事件公共时间字段及如厕/症状/饮食联合模型，使用稳定 UUID，区分实际发生时间与创建/修改时间、时间估计标记。
- 一次如厕支持顺序多便形；排出/没有排出/不确定分开；不适已报告/明确无/未知分开；耗时未知不等于0。
- 饮食区分吃了/明确没吃/未记录；支持多餐及加餐，三餐提醒不替代实际进食时间。
- IndexedDB 持久化、按账号/本机命名空间隔离、原子写入/错误回滚或可恢复反馈；活动如厕和表单草稿可在刷新后恢复。
- 纯函数计算上海时区日期、时间线、完整度、统计与 JSON/CSV 导出；缺失与否定分别处理。
- 云同步接口契约与 outbox：稳定 changeId、基础版本、删除墓碑，幂等重试；发送中继续编辑不能被旧确认覆盖。
**Tests:** 先红后绿的领域与存储测试，覆盖时间排序、跨日、未知值、连续修改、错误反馈、导出及账号隔离。
**Gate:** 公布实际类型/函数契约及测试结果，父验收后才启动依赖这些接口的 UI/云端任务。

## Task 2：原型 UI 和可用记录流程
**Files:** `src/App.tsx`、`src/pages/`、`src/components/`、`src/styles.css`、`public/`。
- 首页真实空态、活动计时（以时间戳计算，锁屏恢复）、完成/补记/编辑/删除。
- 如厕表单：排出状态、1–7型/没看清、顺序多形态、不适、程度/排后变化、实际时间和估计耗时。
- 独立症状记录；饮食表单、明确没吃、常用食物组合的新增/编辑/删除与复用后确认保存。
- 历史按日期与类型筛选；统计支持时段/便形分布、如厕与不适指标、完整度和诚实的空态，不显示未经计算的结论。
- 设置三餐时刻/开关、20分钟稍后提醒与当天停止提醒，前台提醒去重、隐私文案、导出文件实际下载。
- 支持安装用 manifest 与离线应用壳；不缓存第三方认证/数据响应，不声称网页关闭后仍保证提醒。
- 在设置嵌入云连接组件，没配置时不调用假接口、云失败时不静默降级冒充成功；本机模式为用户明确选择。
**Tests:** 浏览器创建三种记录、刷新恢复计时和草稿、编辑删除、历史筛选、统计更新、食物模板、导出、窄屏无横向溢出。

## Task 3：Supabase 接入、权限和配置文档
**Files:** `src/cloud/`、`supabase/migrations/`、`supabase/tests/`、`.env.example`、`README.md`。
- SDK 登录/退出，单账号不提供公开注册入口；退出或换账号立即清除当前 UI 可见数据并隔离本地分区。
- 云记录和设置读写、可重试 outbox、版本冲突提示（保留未同步更改，不静默覆盖）、删除墓碑。
- Postgres 核心记录表以受约束类型与结构化 JSON 表达多便形/饮食内容，独立设置表；UUID、时区时间、索引、版本列和 RLS 所有权检查。
- 浏览器只使用 publishable/anon key，service_role/DB密码不进入前端；禁提交真实记录、备份、凭据。
- 用隔离本机 PostgreSQL 验证迁移及两用户 RLS，夹具身份函数只用于 SQL 测试，不冒称真实 Supabase Auth 验收。
- README 写清免费区选择、手工创建自己的账号并关闭开放注册、配置和迁移步骤、备份、实际网络验收与未启用功能。
**Tests:** SDK/同步契约测试 + 真实隔离 PostgreSQL 迁移/RLS测试；无凭据时明确标记云端 E2E未执行。
