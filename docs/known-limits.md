# 当前边界与后续验收

## 需要真实环境才能完成
- 已接入真实项目公开配置，Auth 入口经物理网卡、不走本机代理返回 HTTP 200；用户执行初始化 SQL 后，肠记表已可识别且匿名读取被 401 拒绝。区域尚未确认；个人账号实际登录/本人读写/跨设备仍待验证。
- SDK/JWT 实际生命周期、两设备同步和国内 Wi-Fi/手机网络尚未验收。单元注入和本机 PostgreSQL 角色测试不替代这些验证。
- 手机 PWA 安装、iOS 离线与系统通知需要真机，不以桌面模拟截图冒充。

## 首版明确未提供
- 照片上传、AI/医学判断、网页关闭后的后台推送。
- 应用锁、本地应用层加密、端到端加密；账号分区不是共享设备安全锁。
- 自动备份、自动导入或一键恢复。JSON/CSV 下载可用，但恢复流程仍需另行实现和验证。

## 非阻塞的已知事项
- 极慢同步期间再次编辑的 debounce 可能并入当前轮次，待同步数据仍留在 outbox 且数量可见；如果没有随后前台/在线事件，可点“立即同步”。后续可补轮次结束后的自动补跑标记。
- 当前生产 JavaScript 单包超过 500KB 阈值，构建保留相应体积警告；不是构建失败，具体大小见实际构建输出。后续可按云模块拆包，不能通过提高阈值冒称已经优化。
- 墓碑、变更日志及幂等账本首版不自动回收，以免旧设备复活已删除记录；接通云项目后需监控真实免费额度。
- 执行真实迁移前，应确认函数由可信迁移角色拥有，并检查 public schema 的 CREATE 权限。迁移不应由普通应用账号执行，不要为排错关闭 RLS。

## 交付权限
代码仅在本机开发与预览。尚未 commit、push、发布或开通付费。所有示例健康记录均为明确标记的合成测试资料；浏览器手工验收样例已经清理，测试导出和报告保留在项目外部的验收目录。
